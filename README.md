AI Engineer (B.Tech AI & ML, 2025) who ships production-style LLM systems end to end: **LangGraph agents, RAG, MCP tool-calling and human-in-the-loop approval**, packaged with Docker, GitHub Actions CI/CD and cloud deployment configs.
